SNS 자동화 & 채널 운영 지원 체크리스트

메디마크가 요청한 "온라인 마케팅 콘텐츠 생성 체계(SNS 자동 업로드 및 콘텐츠 생성)"와 "채널 운영 기술 지원"을 어떻게 다룰지 정리한 자료입니다.

완전 무료 구조 원칙 유지 체크·메모는 이 브라우저에만 저장
회사 공식 자료 확인 결과 — 핵심 사업은 3가지
(주)메디마크(사회적기업, 2022년 설립, 대표 정기국, 서울 성동구)의 공식 소개 자료 기준 핵심 사업:
① 의료분쟁 컨설팅 — 의료기록 열람·복사, 재진단 및 의학적 분석, 의료행위 적절성 평가, 의료과실 판단, 피해구제 컨설팅. 신청 절차: 접수 → 상담배정(자문의) → 자문의 답변작성 → 결제완료(계좌이체) → 회신완료.
② TCI&심리상담 — TCI 기질성격검사, 가족상담, 일반심리상담. 신청 절차: 신청서 작성 → 온라인검사 → 결과해석·상담 → 심층상담.
③ 의료전문 도서 출판 — 「의료사고, 진실을 찾아서」(강윤석 저), 「우리 아이 마음 지도, TCI로 읽다」(이안백 저) 등 다수 출간.

참여 전문가(실명): 정신과 이안백, 소아정신과 김소연, 의료수사 전문 강윤석(경찰 최초 의료수사관 인증 1호), 의학전문기자 장익경, 대표 정기국 — 콘텐츠 저자·출연진으로 바로 활용 가능.

확인이 꼭 필요한 확장 사업 2가지: · TES MIND AI — AI가 사전문진·심리분석·상담기록·리포트를 자동 생성하는 별도 AI 플랫폼 사업(2026.7 계획서), 파주·고양·수원·평택 중학교 5곳에서 시범사업 진행 중. 이번 온라인마케팅 프로젝트와 별개인지 확인 필요. · 글로벌 의료관광 유치사업(global.medimark.co.kr) — 외국인 환자 유치, 미국·일본·중국·중동 등 타겟, 이미 "다국어 웹사이트·SNS·유튜브 운영"을 자체 마케팅 전략으로 명시 — 포함 시 다국어 콘텐츠가 필요해 범위가 커집니다.

블로그 채널 — 전달받은 링크(blog.naver.com/chung389) 기준 네이버 블로그로 추정. 사실이면 공식 자동 게시 API가 없어 반자동 진행이 맞습니다 (확인 필요, 04번 질문 참고).
메디마크TV(유튜브) 콘텐츠는 사업별로 나뉘어 보입니다 — 의료사고 전문가 인터뷰·사건 콘텐츠는 ①, 정신과·MBTI 콘텐츠는 ②를 지원. "실적"의 진짜 기준은 조회수보다 사업별 상담 신청 건수(전환)일 가능성이 큽니다. AI 활용 수준은 "대화·기획서 작성 수준"으로 확인됨 — 무료 채팅 기반 접근이 정확히 맞는 방향입니다.
요구사항 1
온라인 마케팅 콘텐츠 생성 체계
SNS(인스타·페이스북·블로그, +유튜브 확인 필요) 자동 업로드 + 콘텐츠 생성 — ①의료분쟁 컨설팅 · ②TCI&심리상담 · ③의료전문 도서 출판 3개 공식 사업 라인 대응 (TES MIND AI·글로벌 의료관광은 범위 확인 필요)
요구사항 2
채널 운영 기술 지원
보유한 사이트·블로그(blog.naver.com/chung389 추정)·메디마크TV 등 채널 운영 지원. AI 활용도는 대화·기획서 작성 수준으로 확인됨 (유료 API 불필요)
01

SNS 자동 업로드 — 채널별 실행 가능성

채널마다 자동화 가능 여부와 조건이 다릅니다. 먼저 사실관계부터 확인했습니다.

채널자동화조건 · 이유
유튜브 (메디마크TV) 가능 · 대기필요 YouTube Data API로 자동 업로드 가능(무료, 하루 약 6개 업로드 가능한 할당량). 단, Google 앱 검토(컴플라이언스 감사)를 통과하기 전까지 업로드 영상은 비공개로만 처리됨 — 심사 전에는 자동 공개 불가. (공식 문서)
인스타그램 가능 · 대기필요 Meta 공식 Graph API로 진짜 자동 게시 가능. 단, 비즈니스/크리에이터 계정 전환 + 페이스북 페이지 연결 + Meta 앱 심사(2~4주) 필요.
페이스북 가능 · 대기필요 인스타그램과 동일한 Meta 심사 절차 공유. 페이지 관리자 권한 필요.
블로그 (네이버인 경우) 공식 API 없음 네이버는 검색용 API만 공식 제공, 제3자 포스팅 API는 없음. 비공식 자동화는 계정 정지 위험 — 반자동(콘텐츠 준비 후 직접 게시) 권장.
블로그 (티스토리 · 워드프레스 등) 가능 · 확인필요 티스토리·워드프레스는 공식 포스팅 API가 있어 자동 업로드 개발이 가능함. 어느 플랫폼인지 먼저 확인 필요 (04번 질문 참고).
먼저 확인해야 할 것 — "블로그"가 정확히 어느 플랫폼인지, 그리고 유튜브(메디마크TV)도 자동화 범위에 포함할지에 따라 개발 범위가 완전히 달라집니다. 킥오프미팅에서 가장 먼저 확인할 항목입니다.
02

자동화 착수 전 준비물

이 항목이 준비되어야 Meta 앱 등록·심사, 블로그 자동화 개발을 시작할 수 있습니다.

03

채널 운영 기술 지원 + 콘텐츠 생성 — 무료 구조 유지 방법

AI 활용도가 "대화·기획서 작성 수준"으로 확인되어, 유료 API 없이 무료 채팅 기반으로 진행합니다.

04

킥오프미팅에서 확인할 질문

이 요구사항 관련해서 미팅 중 확인하고 바로 메모하세요.

05

진행 로드맵

계정 상태 확인 결과에 따라 일정이 달라질 수 있습니다.

  • 0단계
    킥오프미팅
    블로그 플랫폼 확인, 계정 상태 파악, 콘텐츠 제작 주기 확인
  • 1단계
    계정 준비 (메디마크)
    인스타그램 비즈니스 전환·페이스북 페이지 연결·Business Manager 권한 부여 / 블로그 관리자·API 권한 부여 / (해당 시) 메디마크TV Google Cloud 프로젝트 준비
  • 2단계
    Meta·Google 앱 등록 · 심사 (+ 블로그 API 연동)
    Meta·Google 심사 대기와 별개로, 블로그가 티스토리/워드프레스라면 이 기간에 먼저 자동화 가능
  • 3단계
    자동 게시 개발 · 테스트
    캘린더와 연동해 예약 게시 기능 구현 (무료 서버 활용)
  • 4단계
    콘텐츠 생성 · 채널 운영 지원 템플릿화
    도서·영상 콘텐츠용 프롬프트, 운영 매뉴얼 정리, 재사용 가능하게 정리
참고 — 1~2단계는 저희가 아니라 메디마크 측 계정 설정과 Meta 심사 대기가 관건이라, 이 구간은 저희 작업 속도로 줄일 수 없습니다. 심사 대기 중에도 3단계 코드 골격은 미리 준비할 수 있습니다.
이 문서는 초안입니다. 미팅에서 확인된 내용으로 업데이트하세요.
