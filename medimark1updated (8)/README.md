# 메디마크 온라인마케팅 도구 모음 (배포 파일)

완전 무료 구조로 만든 정적 웹사이트입니다. 서버·데이터베이스·유료 API를 전혀 쓰지 않습니다.

## 구성 파일
- `index.html` — 전체 도구를 모아 보여주는 허브 페이지 (여기서 시작하세요)
- `dashboard.html` — 온라인마케팅 대시보드 (콘텐츠 캘린더 · 체크리스트 · 실적 기록 · 채널 링크 모음)
- `kickoff.html` — 킥오프미팅 준비 자료 (체크리스트 · 아젠다 · 질문지 · 초대 메일 · 회의록)
- `requirements.html` — SNS(인스타·페이스북·블로그·유튜브) 자동화 요구사항 대응 체크리스트
- `pr-support.html` — 채널 운영 지원 도구 (자료정리함 · AI 프롬프트 모음)
- `marketing-app/` — **마케팅 콘텐츠 생성체계 (실제 프로그램 v1)**: 콘텐츠 캘린더 CRUD, 채널·서비스별
  AI 프롬프트 자동 생성(+ Gemini API 등록 시 완전 자동 생성), 초안 저장, 반자동 채널 연동(복사+채널 열기),
  JSON 백업. 데모/문서 4종을 넘어선 실제 동작 프로그램의 1단계입니다.
- `privacy-policy.html` — Meta/Google API 심사 제출용 개인정보처리방침 초안

> ⚠️ Netlify에 재배포할 때는 반드시 이 `medimark-site/` 폴더 **전체**를 올려주세요. `marketing-app/`
> 폴더만 따로 올리면 기존 대시보드·킥오프·요구사항·지원도구 페이지가 사라집니다 (Netlify는 배포마다
> 사이트 전체를 새 내용으로 교체합니다).

## 최근 반영 사항 (카드뉴스 이미지 완전 자동 생성 — Canva 불필요)
- **"채널 연동" 모달의 카드뉴스 채널에 "⚡ 이미지 5장 자동 생성" 버튼 추가.** 한 번 클릭으로:
  1. Gemini가 표지·본문 3장·마무리 문구를 구조화된 형태로 생성 (`data.js`의 `buildCardNewsAutoPrompt`)
  2. 슬라이드마다 Gemini가 제안한 영어 키워드로 **무료 스톡 이미지**(Pexels)를 자동 검색 (신규
     `netlify/functions/search-image.js`, `PEXELS_API_KEY` 환경변수 필요)
  3. 브라우저 `<canvas>`로 이미지 위에 문구를 자동 합성해 카드뉴스 이미지 5장을 즉시 완성 (`app.js`의
     `generateCardNewsAuto`/`compositeCardNewsCanvas` 등)
  4. 이미지별 "다운로드" 버튼으로 PNG 저장 → 바로 인스타그램 등에 게시
- **Canva·유료 API 전혀 사용하지 않음** — Gemini(무료)·Pexels(무료)·브라우저 Canvas API(무료) 조합으로
  "한 번의 명령으로 카드뉴스 완성"을 완전 무료 구조로 구현했습니다 (메디마크 요청서 5-1 항목 대응).
- `PEXELS_API_KEY` 미등록 시에는 안내 메시지만 뜨고, 기존 반자동(문구 복사 → Canva 붙여넣기) 방식이
  그대로 동작합니다 — 화면에 영향 없음.
- Playwright로 성공/미설정(501)/여러 채널 전환 케이스 모두 테스트 완료.

## 최근 반영 사항 (콘텐츠 품질 다듬기 버튼 추가)
- **"AI 프롬프트" 모달에 "품질 다듬기" 버튼 3종 추가**: 🔄 다시 생성 / ✂️ 더 짧게 / 🤝 더 신뢰감 있게.
  AI 자동 생성 결과(또는 직접 붙여넣은 초안)를 대상으로 Gemini에게 재작성을 요청해, 저장 전에
  바로 다듬을 수 있습니다.
- **왜 "100점 만점 자동 채점" 대신 이 방식인가**: LLM이 자기 결과물을 정밀 채점하는 방식은 특히
  "정확성" 항목에서 신뢰하기 어렵습니다(모델이 근거를 검증할 수 없음). 대신 (1) 준수사항처럼
  규칙이 명확한 부분은 결정적 로직으로, (2) 정확성·전문성 같은 판단이 필요한 부분은 사람(검수자)이,
  (3) 톤·길이처럼 사람이 필요할 때 선택적으로 요청할 수 있는 부분은 이 버튼들로 나눠서 처리합니다.

## 가장 쉬운 방법: 그냥 열어보기
`index.html`을 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다. 설치도, 인터넷 연결도 필요 없습니다.

⚠️ 다만 일부 브라우저는 `file://`로 직접 연 페이지에서 데이터 저장(localStorage)을 제한할 수 있습니다.
입력한 내용이 새로고침 후 사라진다면, 아래 "무료 배포" 방법을 사용하세요 — 훨씬 안정적입니다.

## 무료로 배포하는 방법 (권장)

### 방법 A — Netlify Drop (계정 없이 가장 빠름)
1. https://app.netlify.com/drop 접속
2. 이 폴더(`medimark-site`) 전체를 페이지에 드래그 앤 드롭
3. 몇 초 후 `https://무작위이름.netlify.app` 같은 무료 주소가 생성됩니다
4. 완전 무료, 신용카드 불필요

### 방법 B — GitHub Pages
1. GitHub에 새 저장소를 만들고 이 폴더의 파일들을 업로드(push)합니다
2. 저장소 Settings → Pages 로 이동
3. Branch를 `main`, 폴더를 `/ (root)`로 지정 후 저장
4. 잠시 후 `https://아이디.github.io/저장소이름/` 주소로 접속 가능 (완전 무료)

### 방법 C — Vercel, Cloudflare Pages 등
동일하게 폴더를 업로드하거나 저장소를 연결하면 무료로 배포됩니다.

## 데이터에 대해 꼭 알아두실 점
- 입력한 모든 내용(캘린더, 체크리스트, 메모 등)은 **그 페이지를 연 브라우저에만** 저장됩니다.
- 같은 링크를 다른 사람이 열거나, 다른 브라우저/기기에서 열면 **데이터가 공유되지 않습니다.**
- 여러 명이 함께 데이터를 봐야 한다면 별도 구조(예: Google Sheets 연동)가 필요합니다 —
  `dashboard.html`의 "사용자 이름표" 안내에 관련 설명이 있습니다.
