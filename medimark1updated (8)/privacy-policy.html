메디마크 온라인 마케팅 도구 개인정보처리방침

이 문서는 Meta(인스타그램·페이스북)·Google(YouTube) API 심사 제출용 초안입니다. 정식 시행 전 (주)메디마크 내부 검토 및 실제 연락처 반영이 필요합니다.

●서버·데이터베이스 없음 ●브라우저 로컬 저장만 사용

1. 이 방침이 다루는 대상

이 방침은 (주)메디마크가 자사 온라인 채널(유튜브·인스타그램·페이스북·블로그) 운영을 위해 내부적으로 사용하는 콘텐츠 관리 도구 "메디마크 마케팅 콘텐츠 생성체계"(이하 "이 도구")에 적용됩니다. 이 도구는 메디마크 채널 운영 담당자만 사용하며, 일반 방문자·고객이 직접 로그인하거나 정보를 입력하는 서비스가 아닙니다.

2. 수집하는 개인정보

이 도구는 회원가입·로그인 기능이 없으며, 방문자로부터 개인정보를 수집하지 않습니다. 담당자가 입력하는 콘텐츠 캘린더 정보(날짜·채널·주제·담당자 이름·조회수/상담신청 건수 등)는 아래와 같이 처리됩니다.

항목저장 위치외부 전송 여부
콘텐츠 캘린더 데이터사용 중인 브라우저의 localStorage없음 (서버 전송 안 함)
담당자 이름표(사원번호+이름)사용 중인 브라우저의 localStorage없음
SNS 게시 콘텐츠(텍스트·이미지 URL)게시 시점에만 처리Meta Graph API / YouTube Data API로만 전송 (아래 3번 참고)

즉, 이 도구를 운영하는 회사(당사)의 서버는 존재하지 않으며, 입력된 정보는 담당자의 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 해당 정보도 함께 삭제됩니다.

3. SNS API 사용 안내 (Meta / Google)

이 도구는 메디마크가 소유한 SNS 계정에 담당자를 대신해 콘텐츠를 게시하기 위해 아래 API를 사용합니다. 이 과정에서 SNS 이용자(고객·방문자)의 개인정보는 수집·처리하지 않습니다.

  • Meta Graph API — 메디마크 소유 인스타그램 비즈니스 계정·페이스북 페이지에 콘텐츠를 게시하는 용도로만 사용합니다. 페이지 관리자 권한이 있는 담당자의 액세스 토큰을 사용하며, 이 토큰은 서버 측 환경변수(Netlify 환경변수)에만 저장되고 코드나 저장소에 포함되지 않습니다.
  • YouTube Data API v3 — 메디마크TV 채널에 영상을 업로드하는 용도로만 사용합니다. 채널 소유자의 OAuth 갱신 토큰을 사용하며, 마찬가지로 서버 측 환경변수에만 저장됩니다.
참고 — 이 도구는 완전 무료 구조 원칙에 따라 자체 서버·데이터베이스를 두지 않고, API 호출이 필요한 부분만 Netlify Functions(서버리스 함수)를 최소한으로 사용합니다. 이 함수는 요청을 처리하는 순간에만 동작하며 어떤 데이터도 보관하지 않습니다(무상태·stateless).

4. 제3자 제공

수집한 정보를 제3자에게 판매·공유하지 않습니다. 3번 항목에 명시된 대로 콘텐츠 게시 목적의 Meta·Google API 호출을 제외하고는 어떤 외부 서비스로도 데이터를 전송하지 않습니다.

5. 데이터 보관 및 삭제

  • 브라우저 localStorage에 저장된 콘텐츠 캘린더 데이터는 사용자가 언제든 브라우저 설정에서 직접 삭제할 수 있으며, 도구 내 "내보내기(JSON)" 기능으로 백업 후 삭제하는 것을 권장합니다.
  • SNS API 액세스 토큰(환경변수)은 Netlify 대시보드에서 담당 개발자가 직접 삭제·교체할 수 있습니다.
  • 이 도구를 통해 게시된 콘텐츠 자체(게시물·영상)의 삭제는 각 SNS 플랫폼(인스타그램·페이스북·유튜브)의 자체 관리 도구에서 처리합니다.
